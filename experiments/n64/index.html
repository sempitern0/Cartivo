Laboratorio N64

Comprueba la ruta gráfica y la cabecera de un cartucho y, con el núcleo compilado en local (node experiments/n64/build-core.mjs), arranca una sesión real. Experimental: no es soporte de N64.

Solo se leen 64 bytes en un Worker. El archivo no se sube ni se guarda.

Sesión con el núcleo local

Mupen64Plus-Next con GLideN64 dibuja por WebGL2 en un Worker. La demo es un cartucho original de Cartivo. Teclado: flechas = stick, WASD = botones C, K = A, J = B, Enter = Start, Q = Z, I/O = L/R; o un mando estándar (stick derecho = botones C).
